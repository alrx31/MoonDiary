# 02. Открытие приложения и расписание экранов

## Окна времени

| Период | Что открывается при запуске |
|---|---|
| 18:00 — 03:59 | Мастер вечерней записи за текущий день (dayKey). |
| 04:00 — 17:59 | Календарь (главный экран). |

Граница 18:00 входит в окно заполнения, граница 04:00 в окно не входит. С 00:00 до 03:59 текущим днём считается предыдущий календарный день.

## Требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-01.1 | При запуске приложения в окне заполнения сразу открывается мастер вечерней записи, минуя календарь. | Must |
| FR-01.2 | При запуске вне окна заполнения открывается календарь. | Must |
| FR-01.3 | Если вечерняя запись за текущий день уже сохранена, мастер в окне не открывается автоматически. Открывается календарь. | Must |
| FR-01.4 | Пользователь может открыть мастер вручную кнопкой «Заполнить» в любое время, в том числе днём. Если запись за день уже есть, мастер открывает её на редактирование (FR-03.13). | Must |
| FR-01.5 | Если есть готовый еженедельный отчёт, который ещё не показан, он открывается после закрытия мастера или итогового экрана. Если мастер при запуске не открывается, отчёт открывается сразу (FR-06.6). | Must |
| FR-01.6 | Незавершённое заполнение сохраняется как черновик. При следующем запуске мастер открывается чистым; на первой карточке видна ссылка «Есть черновик» (для черновика за тот день, который открыт в мастере), черновики также доступны в «Пользователь → Черновики». | Should |
| FR-01.7 | Время определяется по локальной таймзоне устройства. | Must |
| FR-01.8 | Локальное напоминание о заполнении приходит в 18:00 (время настраивается). Напоминание не приходит, если вечерняя запись за день уже сохранена. | Should |
| FR-01.9 | Напоминание адаптируется: после 14 вечерних записей оно приходит за 10 минут до медианного времени заполнения за последние 14 записей. Записи задним числом не учитываются. | Should |
| FR-01.10 | Напоминание допускает отклонение до 10 минут от назначенного времени. Точные будильники Android (SCHEDULE_EXACT_ALARM) не используются. | Should |

## Пример

- 19:30, запуск: открывается мастер за сегодня.
- 19:30, вечерняя запись уже есть, отчёта нет: открывается календарь.
- 19:30, вечерняя запись есть, есть непоказанный отчёт: открывается отчёт.
- 19:30, записи нет, есть непоказанный отчёт: мастер, после него итоговый экран, затем отчёт.
- 10:00, запуск: открывается календарь.
- 01:00, запуск: открывается мастер за предыдущий календарный день.
