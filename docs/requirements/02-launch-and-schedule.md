# 02. Открытие приложения и расписание экранов

## Окна времени

| Период | Что открывается при запуске |
|---|---|
| 18:00 — 04:00 | Экран заполнения вечерней записи за текущий день. |
| 04:00 — 18:00 | Календарь (главный экран). |

Граница 18:00 включается в окно заполнения, граница 04:00 в окно не входит.

## Требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-01.1 | При запуске приложения в окне заполнения сразу открывается экран заполнения вечерней записи, минуя календарь. | Must |
| FR-01.2 | При запуске вне окна заполнения открывается календарь. | Must |
| FR-01.3 | Если вечерняя запись за текущий день уже заполнена, экран заполнения в окне не открывается автоматически. Открывается календарь. | Must |
| FR-01.4 | Пользователь может открыть экран заполнения вручную из календаря в любое время, в том числе днём. | Must |
| FR-01.5 | Если в окне заполнения есть готовый еженедельный отчёт, который ещё не показан, он открывается после экрана заполнения, а не вместо него (FR-06.6). | Must |
| FR-01.6 | Незавершённое заполнение сохраняется как черновик. При следующем запуске экран заполнения открывается чистым; черновик доступен по отдельной кнопке «Черновики». | Should |
| FR-01.7 | Время определяется по локальной таймзоне устройства. | Must |
| FR-01.8 | Локальное напоминание о заполнении приходит в 18:00 (время настраивается). | Should |
| FR-01.9 | Напоминание адаптируется: после накопления данных приходит за 10 минут до времени, когда пользователь обычно заполняет вечернюю запись. | Could |

## Пример

- 19:30, запуск: открывается заполнение за сегодня.
- 19:30, вечерняя запись уже есть, отчёта нет: открывается календарь.
- 19:30, вечерняя запись есть, есть непоказанный отчёт: открывается отчёт (FR-06.6).
- 10:00, запуск: открывается календарь.
- 01:00, запуск: открывается заполнение за предыдущий календарный день (граница дня — 04:00).
