# 10. Вопросы и решения

Статус по итогам проработки (версия 0.3): все вопросы, кроме отложенных, решены.

## Решено

| ID | Решение | Затрагивает |
|---|---|---|
| Q-01 | Вечернюю запись за текущий день можно редактировать (повторное заполнение редактирует её). При запуске в окне, если запись уже есть, открывается календарь. | FR-01.3, FR-03.13 |
| Q-02 | Граница дня — 04:00: запись/чек-ин до 04:00 относится к предыдущему дню. Окно заполнения — 18:00–04:00. | раздел 02 |
| Q-04 | Карточки и порядок как в разделе 04 (настроение, что сделал, главное достижение, что чувствуешь). | раздел 04 |
| Q-05 | Вариант B: два индикатора (энергия, позитив) на дне. Значение дня — по вечерней записи, при её отсутствии — среднее дневных чек-инов. | FR-05.2 |
| Q-07 | Локальные напоминания: в 18:00, после 14 записей — за 10 минут до медианного времени заполнения. Допустимо отклонение до 10 минут. | FR-01.8–FR-01.10 |
| Q-09 | Направления жизни — из таблицы раздела 07. | FR-06.9 |
| Q-10 | Только Android. Телефон и планшет поддерживаются. | NFR-05 |
| Q-11 | Интерфейс только на русском. | NFR-04 |
| Q-12 | Без пароля и биометрии в первой версии. | NFR-02 |
| Q-13 | Минимум для отчёта — три дня с записями. | FR-06.2 |
| Q-14 | Советы обоих типов (поддерживающие и критичные) в тёплом тоне. | FR-06.8 |
| Q-15 | Достижения фиксируются в вечерней записи. Дневные чек-ины достижений не содержат. | раздел 04 |
| Q-16 | Удаление старых записей разрешено: из карточки дня, с подтверждением. | FR-05.4 |
| Q-17 | Блоки хранятся структурно (id блока + карточка + дата). Текст в поле формируется для показа. | FR-04.10, FR-06.5 |
| Q-18 | Запись можно создать за любой прошедший день; за будущий — нельзя. «Письмо в будущее» — отдельная фича (раздел 12). | FR-05.12 |
| Q-19 | Черновик сохраняется, один на день. Заполнение открывается чистым, черновик доступен по ссылке на первой карточке и в «Черновиках». Сохранение записи удаляет черновик. | FR-01.6, FR-03.19 |
| Q-20 | Отчёт строится при первом запуске начиная с понедельника 04:00, без фонового планировщика. | FR-06.1, FR-06.13 |
| Q-21 | Отчёт охватывает полную неделю (пн–вс). | FR-06.2 |
| Q-22 | Бэкап: и локальный файл экспорта/импорта, и системный Google Backup. | NFR-08, NFR-09 |
| Q-23 | Базовый уровень доступности: системный масштаб шрифта + нецветовой индикатор дня. Полный TalkBack — позже. | NFR-14 |
| Q-24 | Дата-ключ фиксируется в локальной таймзоне на момент записи; время создания хранится в UTC. | FR-01.7 |
| Q-25 | Несколько записей в день допустимы: одна вечерняя + сколько угодно дневных чек-инов. | раздел 04 |
| Q-26 | Жесты мастера: смах вправо пропускает карточку. «Назад», «Сохранить» и выход — кнопками; смах влево не используется. | раздел 04 |
| Q-27 | Хранение: одна база SQLite. DuckDB и JSON-хранение записей не используются. | раздел 11 |
| Q-28 | Импорт заменяет данные целиком, перед этим делается автоматический экспорт. | NFR-08 |
| Q-29 | Каталог правил аналитики и пороги — раздел 15. | FR-06.5 |
| Q-08 | Локальной LLM на устройстве не будет. Для ИИ-советов и автоблоков в будущем — сторонний провайдер (Gemini API). В первой версии — только правила и статистика. | FR-06.4, раздел 12 |
