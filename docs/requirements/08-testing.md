# 08. UI-тестирование

Цель: при обновлениях проверять, что уже сделанное работает. Тесты проверяют интерфейс с точки зрения пользователя: экраны, нажатия, переходы, сохранение.

## Требования

| ID | Требование | Приоритет |
|---|---|---|
| TST-01 | Для каждого сценария из разделов 02–07 есть UI-тест, который запускается автоматически. | Must |
| TST-02 | Тесты работают с приложением как с чёрным ящиком: через элементы интерфейса, без обращения к внутренним классам. | Must |
| TST-03 | Элементы интерфейса имеют стабильные идентификаторы (AutomationId), которые не меняются при смене текста и стилей. | Must |
| TST-04 | Тесты покрывают минимум: открытие по времени (окна 18:00 и 06:00), обязательные шкалы, пропуск карточек, добавление блока, итоговый экран, календарь, открытие отчёта. | Must |
| TST-05 | Тесты используют тестовые данные. Реальная база пользователя не затрагивается. | Must |
| TST-06 | Время в тестах подменяется, чтобы проверять окна 18:00 и 06:00 без ожидания. | Must |
| TST-07 | Тесты запускаются на Android-устройстве или эмуляторе и не требуют ручных действий. | Must |
| TST-08 | Перед каждым обновлением (релизом или слиянием в main) тесты запускаются. Упавший тест блокирует слияние. | Should |
| TST-09 | Отчёт о прогоне сохраняется: какие сценарии прошли, какие упали, скриншоты при падении. | Should |
| TST-10 | Тесты не проверяют цвета, точные отступы и тексты советов. Проверяются наличие элементов и результат действия. | Should |
| TST-11 | Доменная логика (аналитика, агрегация дня, границы окна, целостность данных) покрыта модульными тестами. | Should |

## Сценарии (минимальный набор)

| Сценарий | Связанное требование |
|---|---|
| Запуск в 19:00 открывает заполнение | FR-01.1 |
| Запуск в 10:00 открывает календарь | FR-01.2 |
| Запуск в 18:00 включает окно заполнения | FR-01.1, FR-01.7 |
| Запуск в 06:00 открывает календарь | FR-01.2 |
| Без выбора обеих шкал «Далее» не работает | FR-03.2 |
| Пропуск карточек 2–4 и сохранение | FR-03.5, FR-03.6 |
| Нажатие блока добавляет подпись в поле | FR-04.3 |
| Итоговый экран показан после сохранения | FR-03.9 |
| Запись видна в календаре на нужном дне | FR-05.2, FR-05.4 |
| Отчёт открывается после заполнения в окне | FR-01.5, FR-06.6 |

## Открытый вопрос

Платформа определена: только Android (Q-10). Инструмент для UI-тестов на Android выбирается при разработке. Для MAUI возможны Appium с драйвером UiAutomator2 или нативные средства Android.
