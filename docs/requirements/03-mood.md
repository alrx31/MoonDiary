# 03. Настроение

Настроение задаётся по двум независимым шкалам. Каждая шкала имеет пять делений. У каждого деления своя иконка.

## Шкалы

| Шкала | Что измеряет | Деления (от низкого к высокому) |
|---|---|---|
| Энергия | Уровень сил и бодрости | 1 — истощение, 2 — усталость, 3 — ровно, 4 — бодрость, 5 — подъём |
| Позитив | Общий эмоциональный фон | 1 — плохо, 2 — грустно, 3 — нейтрально, 4 — хорошо, 5 — отлично |

Названия делений даны для ориентира. Иконки пользователь подготовит позже (Q-03). До этого в первой версии и макетах шкала выглядит как ряд из 5 кругов (как звёзды в рейтинге): нажатие выбирает значение 1–5, выбранные круги подсвечиваются.

## Требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-02.1 | Для записи обязательно выбрать значение по шкале «Энергия» (1–5). | Must |
| FR-02.2 | Для записи обязательно выбрать значение по шкале «Позитив» (1–5). | Must |
| FR-02.3 | Под шкалой показывается подпись выбранного деления («бодрость», «хорошо»). | Must |
| FR-02.9 | Каждое деление отображается своей иконкой, иконка понятна без подписи. Делается после Q-03, до этого — круги. | Could |
| FR-02.4 | Выбранное деление подсвечивается. Повторное нажатие на выбранное значение ничего не сбрасывает. | Should |
| FR-02.5 | Значения шкал хранятся как целые числа от 1 до 5 независимо друг от друга. | Must |
| FR-02.6 | Значения шкал можно изменить после сохранения записи через карточку дня, в том числе за прошедшие дни (FR-05.5). | Should |
| FR-02.7 | Обе шкалы выбираются на первой карточке мастера заполнения (FR-03.2). | Must |
| FR-02.8 | Дневной чек-ин (раздел 04) использует те же две шкалы. | Must |

## Зачем две шкалы

Энергия и позитив расходятся. Человек может быть уставшим, но довольным, или бодрым, но подавленным. Одна общая оценка этого не показывает, поэтому анализ (раздел 07) опирается на обе шкалы отдельно.
