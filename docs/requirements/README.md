## Как читать номера

- `G-xx` цель продукта.
- `FR-NN.M` функциональное требование: `NN` раздел, `M` пункт внутри раздела.
- `NFR-xx` нефункциональное требование.
- `TST-xx` требование к тестированию.
- `Q-xx` вопрос с решением.
- `S-xx` функция из бэклога.
- `AR-xx` правило аналитики.

## Приоритеты

- **Must**: без этого приложение не выполняет свою цель.
- **Should**: нужно для полноценной работы, но можно отложить на следующий этап.
- **Could**: идея, которая пока не входит в объём.

Приоритет указан в каждом требовании.

## Словарь

- **Вечерняя запись (entry)**: главная запись дня, заполняется вечером через мастер карточек. Одна на день.
- **Дневной чек-ин (check-in)**: быстрая отметка настроения в течение дня (две шкалы + короткий текст). Несколько в день.
- **Запись**: вечерняя запись или дневной чек-ин.
- **Окно заполнения**: период с 18:00 до 04:00 локального времени, в котором приложение при запуске открывает вечернюю запись.
- **Карточка**: один экран мастера заполнения.
- **Блок-подсказка (тег)**: готовая короткая фраза с иконкой, которую можно нажать вместо набора текста.
- **Энергия**, **позитив**: две шкалы настроения по пять делений каждая.
- **Неделя**: период с понедельника по воскресенье.
- **Отчёт**: результат еженедельного анализа.
- **День (dayKey)**: период с 04:00 одного календарного дня до 04:00 следующего. Запись или чек-ин, сделанные с 00:00 до 03:59, относятся к предыдущему календарному дню.
- **Черновик**: незавершённое заполнение вечерней записи. Не больше одного на день.
