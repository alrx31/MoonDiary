# 04. Вечернее заполнение и дневные чек-ины

## Два вида записей

- **Вечерняя запись** — главная запись дня. Одна на день, заполняется через мастер карточек. Определяет цвет дня в календаре и основной сигнал недельного отчёта.
- **Дневной чек-ин** — быстрая отметка состояния в любой момент дня: две шкалы настроения и короткий текст. Несколько в день, без мастера.

## Карточки вечерней записи

Мастер оформлен как стопка карточек на весь экран, листаемых вперёд. Первая карточка обязательна, остальные можно пропустить.

| № | Карточка | Обязательна | Содержимое |
|---|---|---|---|
| 1 | Настроение | Да | Две шкалы (раздел 03). |
| 2 | Что сделал за день | Нет | Поле ввода и блоки-подсказки (раздел 05). |
| 3 | Главное достижение | Нет | Поле ввода и блоки-подсказки (раздел 05). |
| 4 | Что чувствуешь | Нет | Поле ввода и блоки-подсказки (раздел 05). |
| 5 | Итог | — | Экран благодарности (FR-03.9). |

Порядок карточек 2–4 фиксирован.

## Управление мастером

| Действие | Где | Что делает |
|---|---|---|
| «Продолжить» | внизу карточки | следующая карточка; на карточке 4 — сохранение и итоговый экран |
| «Сохранить» | шапка, карточки 1–4 | сохраняет запись с тем, что уже заполнено, и показывает итоговый экран |
| Смах вправо | карточки 2–4 | пропуск карточки, то же, что «Продолжить» с пустым полем |
| «Назад» | шапка, системная кнопка или жест «назад» Android | предыдущая карточка; на карточке 1 — выход с черновиком |
| «✕» | шапка | выход: заполненное сохраняется как черновик |

Смах влево не используется: его легко сделать случайно, и он совпадает с системным жестом «назад» у правого края экрана.

## Требования к вечерней записи

| ID | Требование | Приоритет |
|---|---|---|
| FR-03.1 | Заполнение открывается как последовательность карточек на весь экран. | Must |
| FR-03.2 | Первая карточка содержит две шкалы настроения. Пока обе не выбраны, «Продолжить», «Сохранить» и смах неактивны. | Must |
| FR-03.3 | Переход к следующей карточке — кнопкой «Продолжить» внизу карточки. | Must |
| FR-03.4 | Вернуться к предыдущей карточке можно кнопкой «Назад» в шапке или системным «назад». Введённый текст при этом не теряется. | Must |
| FR-03.5 | Карточки 2–4 можно пропустить смахом вправо. Пропуск не требует ввода. | Must |
| FR-03.6 | Кнопка «Сохранить» в шапке карточек 1–4 сохраняет запись с уже заполненными карточками. Остальные остаются пустыми. | Must |
| FR-03.18 | Кнопка «✕» и «Назад» на карточке 1 закрывают мастер. Если выбрано хотя бы одно значение или введён текст, прогресс сохраняется как черновик. | Should |
| FR-03.7 | Текст карточки сохраняется при переходах вперёд, назад и при пропуске следующих карточек. | Should |
| FR-03.8 | Текст одной карточки ограничен 500 символами. Счётчик виден, когда осталось меньше 50. | Should |
| FR-03.9 | После сохранения показывается итоговый экран с благодарностью. Тексты благодарности хранятся в ресурсном файле и выбираются случайно. | Must |
| FR-03.10 | Итоговый экран показывает краткую сводку дня: два значения шкал и количество заполненных карточек. | Should |
| FR-03.11 | Итоговый экран закрывается кнопкой «Готово» или автоматически через 5 секунд. Дальше открывается непоказанный отчёт (FR-01.5), если он есть, иначе календарь. | Should |
| FR-03.12 | Минимальная запись (только шкалы) делается за 3 касания и до 15 секунд, типичная — до минуты (G-02). | Should |
| FR-03.13 | Повторное заполнение вечерней записи за тот же день редактирует её. Мастер открывается с сохранёнными значениями. | Must |
| FR-03.19 | При сохранении вечерней записи черновик за этот день удаляется. | Must |
| FR-03.20 | Запись за прошедший день открывается из карточки этого дня (FR-05.12). В шапке мастера видна дата дня, за который делается запись. | Must |

## Требования к дневному чек-ину

| ID | Требование | Приоритет |
|---|---|---|
| FR-03.14 | Чек-ин — это быстрый экран: две шкалы настроения и короткий текст (до 500 символов). Шкалы обязательны, текст нет. | Must |
| FR-03.15 | Чек-ин доступен в любое время из календаря. Чек-ин относится к текущему dayKey (с 00:00 до 03:59 — под предыдущий календарный день), задним числом не создаётся. | Must |
| FR-03.16 | Чек-ин сохраняется отдельной записью. Несколько чек-инов в день допустимы. | Must |
| FR-03.17 | Чек-ин не открывает мастер карточек. | Must |
| FR-03.21 | Чек-ин можно отредактировать или удалить из карточки дня (с подтверждением). | Should |

## Сценарии

Минимальный вечер (3 касания):

1. Открывается мастер (FR-01.1).
2. Карточка 1: энергия 4, позитив 4.
3. «Сохранить», итоговый экран.

Типичный вечер (5–6 касаний):

1. Карточка 1: энергия 4, позитив 4, «Продолжить».
2. Карточка 2: блок «работа», «Сохранить».
3. Итоговый экран.
