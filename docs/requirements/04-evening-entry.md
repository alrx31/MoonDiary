# 04. Вечернее заполнение и дневные чек-ины

## Два вида записей

- **Вечерняя запись** — главная запись дня. Одна на день, заполняется через полный мастер карточек. Определяет цвет дня в календаре и основной сигнал недельного отчёта.
- **Дневной чек-ин** — быстрая отметка состояния в любой момент дня: две шкалы настроения и короткий текст. Несколько в день, без полного мастера.

## Карточки вечерней записи

Заполнение оформлено как последовательность карточек, листаемых вперёд, в стиле Tinder. Первая карточка обязательна. Остальные необязательны и могут быть пропущены.

| № | Карточка | Обязательна | Содержимое |
|---|---|---|---|
| 1 | Настроение | Да | Две шкалы (раздел 03). |
| 2 | Что сделал за день | Нет | Поле ввода и блоки-подсказки (раздел 05). |
| 3 | Главное достижение | Нет | Поле ввода и блоки-подсказки (раздел 05). |
| 4 | Что чувствуешь | Нет | Поле ввода и блоки-подсказки (раздел 05). |
| 5 | Итог | — | Экран благодарности (FR-03.9). |

Порядок карточек 2–4 фиксирован.

## Требования к вечерней записи

| ID | Требование | Приоритет |
|---|---|---|
| FR-03.1 | Заполнение открывается как последовательность карточек на весь экран. | Must |
| FR-03.2 | Первая карточка содержит две шкалы настроения. Без выбора обеих значений дальше не переходим. | Must |
| FR-03.3 | Переход к следующей карточке — кнопкой «Продолжить» внизу карточки. | Must |
| FR-03.4 | Вернуться к предыдущей карточке можно жестом или кнопкой «Назад». Введённый текст при этом не теряется. | Must |
| FR-03.5 | Карточки 2–4 можно пропустить смахом вправо. Пропуск не требует ввода. | Must |
| FR-03.18 | Смах влево заканчивает заполнение: прогресс сохраняется как черновик, его можно продолжить позже. | Should |
| FR-03.6 | Сохранить запись можно уже после первой карточки. Остальные карточки при этом не заполняются. | Must |
| FR-03.7 | Карточка с текстом сохраняет введённый текст даже при пропуске следующей карточки. | Should |
| FR-03.8 | Текст одной карточки ограничен 500 символами. Счётчик виден, когда осталось меньше 50. | Should |
| FR-03.9 | После последней карточки показывается итоговый экран с благодарностью. Текст можно менять без пересборки приложения. | Must |
| FR-03.10 | Итоговый экран показывает краткую сводку дня: два значения шкал и количество заполненных карточек. | Should |
| FR-03.11 | Итоговый экран закрывается кнопкой или автоматически через 5 секунд. | Should |
| FR-03.12 | Вся запись занимает не больше двух минут при типичном сценарии. | Should |
| FR-03.13 | Повторное заполнение вечерней записи за тот же день редактирует её, а не создаёт новую. | Must |

## Требования к дневному чек-ину

| ID | Требование | Приоритет |
|---|---|---|
| FR-03.14 | Чек-ин — это быстрый экран: две шкалы настроения и короткий текст (до 500 символов). | Must |
| FR-03.15 | Чек-ин доступен в любое время, в том числе вне окна заполнения, из календаря. | Must |
| FR-03.16 | Чек-ин сохраняется отдельной записью. Несколько чек-инов в день допустимы. | Must |
| FR-03.17 | Чек-ин не открывает полный мастер карточек. | Must |

## Сценарий типичного вечера

1. Открывается приложение, экран заполнения (FR-01.1).
2. Карточка 1: выбраны энергия 4 и позитив 4. Жест «Далее».
3. Карточка 2: нажат блок «работа сделана» и «пропустить» на остальных карточках.
4. Сохранение, итоговый экран.

Всего четыре касания при минимальном сценарии.
