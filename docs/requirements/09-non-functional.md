# 09. Нефункциональные требования

| ID | Требование | Приоритет |
|---|---|---|
| NFR-01 | Приложение работает полностью без интернета. | Must |
| NFR-02 | Данные хранятся на устройстве в локальной базе. Формат и место хранения выбираются при разработке (см. раздел 11). | Must |
| NFR-03 | Экран заполнения открывается за время, не заметное пользователю (до 1 секунды на типичном устройстве). | Should |
| NFR-04 | Интерфейс на русском языке. Другие языки не требуются в первой версии. | Must |
| NFR-05 | Приложение работает только на Android. Интерфейс адаптивен: одинаково работает на телефоне и планшете. | Must |
| NFR-06 | Тексты, пороги и наборы блоков хранятся отдельно от кода, чтобы их можно было менять без выпуска новой версии. | Should |
| NFR-07 | Записи не теряются при закрытии приложения во время заполнения: черновик сохраняется. | Must |
| NFR-08 | Экспорт данных в локальный файл и импорт из него. | Should |
| NFR-09 | Резервная копия: включён системный бэкап Android (Google Backup) и доступен локальный файл. Пользователь не привязан к устройству. | Should |
| NFR-10 | Анализ не должен заметно нагружать устройство: отчёт за неделю строится за несколько секунд. | Should |
| NFR-11 | Сбой сохранения, повреждение БД или заполненный диск не приводят к потере всех данных: есть восстановление или понятное сообщение. | Should |
| NFR-12 | Пустые состояния: при первом запуске и отсутствии записей экраны показывают понятные подсказки. | Should |
| NFR-13 | Обновление приложения не теряет данные: схема БД мигрирует между версиями. | Must |
| NFR-14 | Цвет дня в календаре не является единственным индикатором: он дублируется иконкой или точкой (доступность, дальтонизм). Системный масштаб шрифта работает. | Should |
