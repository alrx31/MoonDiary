# 11. Модель данных

Описывает сущности и хранение. Типы указаны как ориентир, точная схема делается при разработке.

## Принцип хранения

- Одна база SQLite во внутреннем хранилище приложения (Q-27). Доступ через EF Core или sqlite-net, выбирается при разработке.
- Объём маленький (около 365 вечерних записей в год), аналитика считается запросами к той же базе.
- Схема имеет номер версии и мигрирует при обновлении (NFR-13).
- Время создания и изменения хранится в UTC, день записи — как локальная дата (Q-24).

## Сущности

### Запись (Entry)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор записи |
| type | enum | `evening` (вечерняя) или `checkin` (дневной чек-ин) |
| dayKey | date | День, к которому относится запись (граница 04:00) |
| energy | int 1–5 | Шкала «Энергия» |
| positivity | int 1–5 | Шкала «Позитив» |
| done | text, ≤500 | Карточка «Что сделал за день» (только evening) |
| achievement | text, ≤500 | Карточка «Главное достижение» (только evening) |
| feelings | text, ≤500 | Карточка «Что чувствуешь» (только evening) |
| checkinText | text, ≤500 | Короткий текст чек-ина (только checkin) |
| createdAtUtc | datetime | Момент создания в UTC |
| updatedAtUtc | datetime | Момент последнего изменения в UTC |
| timezoneOffset | int | Офсет таймзоны в минутах в момент создания (Q-24) |
| isBackfilled | bool | Запись создана задним числом (FR-05.12). Не учитывается в адаптивном напоминании (FR-01.9) |

### Блок-подсказка (Tag)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор блока |
| cardType | enum | Карточка: `done` / `achievement` / `feelings` |
| label | text, ≤3 слов | Подпись блока |
| icon | text | Ключ иконки из набора приложения |
| direction | enum | Направление жизни: `sleep`, `work`, `health`, `relations`, `household`, `emotions`, `none` (FR-04.12) |
| color | text, null | Цвет блока (S-11), пока не используется |
| order | int | Порядок показа |
| useCount | int | Счётчик использований (FR-04.7) |
| isCustom | bool | Создан пользователем |
| isArchived | bool | Удалён из подсказок, но остаётся в истории (FR-04.13) |

### Связь «запись — блок» (EntryTag)

Структурное хранение выбранных блоков для аналитики (Q-17, FR-04.11).

| Поле | Тип | Описание |
|---|---|---|
| entryId | guid | Запись |
| tagId | guid | Блок |
| cardType | enum | Карточка, на которой выбран блок |

Первичный ключ: (entryId, tagId, cardType).

### Отчёт (Report)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор отчёта |
| weekStart | date | Понедельник недели |
| generatedAtUtc | datetime | Момент построения |
| status | enum | `ok` или `insufficientData` (AR-05) |
| daysWithEntries | int | Дней с записями за неделю |
| content | json | Готовые части отчёта: итоги, достижения, закономерности, сравнение с прошлой неделей. Четвёртая часть — советы — хранится отдельно в ReportAdvice, потому что у каждого совета есть оценка |
| shownAtUtc | datetime, null | Когда отчёт показан автоматически (FR-06.6). Пусто — ещё не показан |

### Совет в отчёте (ReportAdvice)

| Поле | Тип | Описание |
|---|---|---|
| reportId | guid | Отчёт |
| ruleId | text | Правило из раздела 15 (например, `AR-31`) |
| direction | enum | Направление жизни |
| text | text | Готовый текст совета |
| feedback | enum, null | `useful` / `notRelevant` (FR-06.12) |

### Черновик (Draft)

| Поле | Тип | Описание |
|---|---|---|
| dayKey | date | День; первичный ключ, один черновик на день |
| content | json | Выбранные шкалы, тексты карточек, выбранные блоки, номер текущей карточки |
| updatedAtUtc | datetime | Последнее изменение |

### Письмо (Letter)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор письма |
| text | text, ≤5000 | Текст письма |
| createdAtUtc | datetime | Момент создания |
| openDate | date | Дата открытия, не раньше завтрашнего дня |
| openedAtUtc | datetime, null | Когда письмо стало доступно. Пусто — закрыто |
| notified | bool | Уведомление об открытии отправлено |

### Настройки (Settings)

| Поле | Тип | Описание |
|---|---|---|
| reminderEnabled | bool | Напоминание включено |
| reminderTime | time | Время напоминания (по умолчанию 18:00) |
| adaptiveReminder | bool | Адаптивное напоминание включено |
| theme | enum | Тема: светлая / тёмная / авто |
| userName | text, null | Имя пользователя (S-08) |
| onboardingDone | bool | Первый запуск пройден (NFR-15) |

## Ограничения целостности

- Одна вечерняя запись на `dayKey` (уникальный индекс по `type=evening, dayKey`).
- Дневных чек-инов на `dayKey` может быть сколько угодно.
- `energy` и `positivity` — целые в диапазоне 1–5 (CHECK).
- Запись за будущий `dayKey` запрещена. Проверяется в коде, так как зависит от текущего времени.
- Блоки не удаляются физически, если на них есть ссылки в EntryTag: ставится `isArchived`.
- Один отчёт на `weekStart` (уникальный индекс).
