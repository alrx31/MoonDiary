# 11. Модель данных

Описывает сущности и хранение. Как именно реализовать (конкретная БД, ORM) решается при разработке. Формат ниже — ориентир.

## Принцип хранения

- Запись — гибкая модель (например, JSON) в локальной БД на устройстве.
- Для аналитики допускается локальная встраиваемая БД (например, DuckDB), в которую записи дублируются или из которой читаются агрегаты. Решение принимается при разработке; офлайн-ограничение сохраняется.

## Сущности

### Запись (Entry)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор записи |
| type | enum | `evening` (вечерняя) или `checkin` (дневной чек-ин) |
| dayKey | date | Календарный день, к которому относится запись (по границе 04:00) |
| energy | int 1–5 | Шкала «Энергия» |
| positivity | int 1–5 | Шкала «Позитив» |
| done | text, ≤500 | Карточка «Что сделал за день» (только evening) |
| achievement | text, ≤500 | Карточка «Главное достижение» (только evening) |
| feelings | text, ≤500 | Карточка «Что чувствуешь» (только evening) |
| checkinText | text, ≤500 | Короткий текст чек-ина (только checkin) |
| createdAtUtc | datetime | Момент создания в UTC |
| timezoneOffset | int | Офсет таймзоны в момент создания (Q-24) |

### Блок-подсказка (Tag)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор блока |
| cardType | enum | К какой карточке относится (done / achievement / feelings) |
| label | text, ≤3 слов | Подпись блока |
| icon | ref | Иконка |
| order | int | Порядок показа |
| useCount | int | Счётчик использований (для сортировки по частоте) |
| isCustom | bool | Создан пользователем или предложен приложением |

### Связь «запись — блок» (EntryTag)

Структурное хранение выбранных блоков для аналитики (Q-17).

| Поле | Тип | Описание |
|---|---|---|
| entryId | guid | Запись |
| tagId | guid | Блок |
| cardType | enum | Карточка, на которой выбран блок |

### Отчёт (Report)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор отчёта |
| weekStart | date | Понедельник недели |
| summary | text | Итоги недели |
| achievements | text | Достижения |
| patterns | text | Закономерности |
| advice | json | Советы по направлениям с оценками (FR-06.12) |
| shown | bool | Был ли показан (FR-06.6) |

### Черновик (Draft)

| Поле | Тип | Описание |
|---|---|---|
| id | guid | Идентификатор черновика |
| dayKey | date | К какому дню относится |
| content | json | Выбранные шкалы и тексты карточек |
| updatedAt | datetime | Последнее изменение |

### Настройки (Settings)

| Поле | Тип | Описание |
|---|---|---|
| reminderTime | time | Время напоминания (по умолчанию 18:00) |
| adaptiveReminder | bool | Адаптивное напоминание включено |
| theme | enum | Тема (светлая/тёмная/авто) |
| userName | text | Имя пользователя (для отчёта и благодарности) |
| reportDay/time | — | Настройки запуска отчёта |

## Ограничения целостности

- Одна вечерняя запись на `dayKey` (уникальный индекс по `type=evening, dayKey`).
- Дневных чек-инов на `dayKey` может быть сколько угодно.
- `energy` и `positivity` — целые в диапазоне 1–5 (CHECK).
- Запись за будущий `dayKey` запрещена.
