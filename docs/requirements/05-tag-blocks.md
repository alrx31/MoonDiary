# 05. Блоки-подсказки

Под полем ввода карточек 2–4 показываются готовые блоки с иконками. Нажатие на блок добавляет его текст в поле. Блоки нужны, чтобы не писать одно и то же каждый день.

## Требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-04.1 | Под полем ввода карточки 2, 3 и 4 показывается набор из не более 10 готовых блоков. | Must |
| FR-04.2 | Каждый блок состоит из иконки и короткой подписи (до 3 слов). | Must |
| FR-04.3 | Нажатие на блок добавляет его подпись в поле ввода. Если поле уже содержит текст, подпись дописывается через пробел или запятую. | Must |
| FR-04.10 | Выбранный блок сохраняется структурно (id блока + запись + карточка), чтобы аналитика находила закономерности без разбора текста. Текст в поле формируется для показа. | Must |
| FR-04.11 | При сохранении записи связь с блоком остаётся, только если подпись блока встречается в тексте карточки как точная подстрока (подпись сравнивается как есть, без морфологии). Если пользователь стёр подпись вручную, связь удаляется. | Must |
| FR-04.12 | Каждый блок относится к одному направлению жизни (раздел 07) или к направлению «Без направления». Для стартовых блоков направление задано заранее, для своих пользователь выбирает его при создании. | Must |
| FR-04.13 | Удалённый блок пропадает из подсказок, но остаётся в истории записей и аналитике. Переименование блока не меняет текст старых записей. | Must |
| FR-04.4 | Блок можно нажать повторно, чтобы убрать его из текста. | Should |
| FR-04.5 | Набор блоков разный для каждой карточки (карточка 2, 3, 4). | Must |
| FR-04.6 | Набор блоков пользователь может менять: добавлять, удалять, переставлять. Список хранится на устройстве. | Should |
| FR-04.7 | Блоки, которые пользователь использовал чаще других, показываются первыми. | Could |
| FR-04.8 | Приложение предлагает новые блоки из фраз, которые пользователь часто пишет вручную. Работает локально, без облачного ИИ. | Should |
| FR-04.9 | Поле ввода работает и без блоков. Блоки не обязательны. | Must |

## Стартовый набор (черновик, уточняется)

В скобках указано направление жизни (раздел 07).

Карточка «Что сделал за день»:

- работа (работа и учёба)
- учёба (работа и учёба)
- спорт (здоровье и спорт)
- готовка (быт)
- уборка (быт)
- встреча (отношения)
- покупки (быт)
- прогулка (здоровье и спорт)
- чтение (без направления)
- отдых (сон)

Карточка «Главное достижение»:

- сдал задачу (работа и учёба)
- закончил проект (работа и учёба)
- выучил новое (работа и учёба)
- справился с трудным (эмоции)
- помог кому-то (отношения)
- привёл себя в порядок (здоровье и спорт)
- вовремя сделал (работа и учёба)
- начал новое (без направления)
- преодолел страх (эмоции)
- порадовал себя (эмоции)

Карточка «Что чувствуешь»:

- спокойно (эмоции)
- благодарен (эмоции)
- устал (сон)
- тревожно (эмоции)
- радостно (эмоции)
- раздражён (эмоции)
- мотивирован (эмоции)
- одиноко (отношения)
- вдохновлён (эмоции)
- сонно (сон)

Иконки для блоков подбираются отдельно. Формулировки в наборах заменяются на реальные по итогам первых недель использования.
