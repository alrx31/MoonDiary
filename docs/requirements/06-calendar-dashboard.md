# 06. Главный экран: календарь и дашборд

Календарь — основной экран вне окна заполнения. Это дашборд: видно настроение по дням и значимые достижения.

## Требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-05.1 | Экран показывает календарь текущего месяца с отметкой каждого дня. | Must |
| FR-05.2 | День с записями окрашен по настроению: берётся вечерняя запись, при её отсутствии — среднее дневных чек-инов (округление до целого). Две шкалы показываются двумя индикаторами (вариант B, Q-05). | Must |
| FR-05.3 | Дни без записи видны и отличаются от дней с записью. | Must |
| FR-05.4 | Нажатие на день открывает карточку записи: вечернюю запись (шкалы, сделанное, достижение, чувства) и список дневных чек-инов. | Must |
| FR-05.5 | Из карточки дня запись можно отредактировать. | Should |
| FR-05.6 | Переключение между месяцами свайпом или стрелками. | Must |
| FR-05.7 | Блок «Достижения»: список главных достижений за выбранный месяц с датами. | Should |
| FR-05.8 | Блок «Динамика»: график значений шкал за последние 4 недели. | Should |
| FR-05.9 | Блок «Серия»: сколько дней подряд заполнен дневник. | Could |
| FR-05.10 | Блок «Последний отчёт»: ссылка на последний еженедельный отчёт (раздел 07). | Should |
| FR-05.11 | Кнопки «Заполнить сегодня» и «Чек-ин» всегда доступны на главном экране. | Must |
| FR-05.12 | Запись можно сделать за любой прошедший день. Запись за будущий день запрещена. | Must |
| FR-05.13 | Календарь оформлен как кастомный «красивый» вид: месяц раскрашен по настроению и читается с одного взгляда. | Should |

## Состав главного экрана

Сверху вниз: кастомный календарь месяца, под ним — список дней, внизу — нижняя панель.

Нижняя панель: «Календарь», «Аналитика», «Заполнить» (центральная кнопка), «Письма», «Пользователь». «Настройки» и «Черновики» — внутри «Пользователя».

Блоки «Достижения», «Динамика», «Последний отчёт» и «Серия» вынесены на страницу «Аналитика». Детали — в разделе 13 (wireframe-спецификация).
