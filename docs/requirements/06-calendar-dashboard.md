# 06. Главный экран: календарь

Календарь — основной экран вне окна заполнения. По нему видно настроение по дням месяца.

## Требования к календарю

| ID | Требование | Приоритет |
|---|---|---|
| FR-05.1 | Экран показывает календарь текущего месяца с отметкой каждого дня. | Must |
| FR-05.2 | День с записями показывает два индикатора: энергию и позитив (вариант B, Q-05). Значение берётся из вечерней записи, при её отсутствии — среднее дневных чек-инов, округлённое до целого по обычным правилам (2,5 → 3). | Must |
| FR-05.3 | Дни без записи видны и отличаются от дней с записью. | Must |
| FR-05.4 | Нажатие на день открывает карточку дня: вечернюю запись (шкалы, сделанное, достижение, чувства) и список дневных чек-инов. | Must |
| FR-05.5 | Из карточки дня вечернюю запись можно отредактировать или удалить (с подтверждением, Q-16). Удаление вечерней записи не удаляет чек-ины. | Should |
| FR-05.6 | Переключение между месяцами свайпом или стрелками. Перейти на месяц позже текущего нельзя. | Must |
| FR-05.11 | Кнопка «Заполнить» в нижней панели доступна на всех страницах. Кнопка «Чек-ин» есть на календаре. | Must |
| FR-05.12 | Запись можно сделать за любой прошедший день: карточка пустого дня показывает кнопку «Заполнить за этот день». Запись за будущий день запрещена, будущие дни не нажимаются. | Must |
| FR-05.13 | Календарь оформлен как кастомный вид: месяц раскрашен по настроению и читается с одного взгляда. | Should |
| FR-05.14 | Под календарём — лента дней выбранного месяца, от новых к старым. В строке дата, два значения шкал и короткий текст дня (достижение или первый блок), которого нет в сетке календаря. | Should |

## Требования к странице «Аналитика»

Номера сохранены с прошлой версии, когда эти блоки были на главном экране.

| ID | Требование | Приоритет |
|---|---|---|
| FR-05.7 | Блок «Достижения»: список главных достижений за выбранный месяц с датами. | Should |
| FR-05.8 | Блок «Динамика»: график значений шкал за последние 4 недели. | Should |
| FR-05.9 | Блок «Серия»: сколько дней подряд есть вечерняя запись. Серия не прерывается, если сегодняшняя запись ещё не сделана. | Could |
| FR-05.10 | Блок «Последний отчёт» и ссылка «Все отчёты» на историю отчётов (FR-06.7). | Should |

## Состав главного экрана

Сверху вниз: кастомный календарь месяца, под ним лента дней, внизу нижняя панель.

Нижняя панель: «Календарь», «Аналитика», «Заполнить» (центральная кнопка), «Письма», «Пользователь». «Настройки», «Черновики» и «Блоки-подсказки» находятся внутри «Пользователя».

Детали экранов — в разделе 13.
