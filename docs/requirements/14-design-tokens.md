# 14. Цветовая палитра

Дизайн-токены. Тёмная тема зафиксирована, светлая — позже.

## Тёмная тема («Чернила и лунное золото»)

Выбрана из вариантов генерации (правый верхний). Тёплый тёмный фон + лунное золото и приглушённый тил вместо типичных «иишных» фиолетово-синих градиентов.

| Роль | Hex | Применение |
|---|---|---|
| Фон | `#14161C` | основной фон экранов |
| Поверхность | `#1E2129` | карточки, ячейки |
| Поверхность приподнятая | `#262A34` | модалки, меню |
| Рамки / разделители | `#2E323D` | границы, сплиттеры |
| Текст основной | `#EDEAE2` | заголовки, текст |
| Текст вторичный | `#A9ADB8` | подписи |
| Текст приглушённый | `#6B6E78` | даты, пустые состояния |
| Акцент «Энергия» | `#E0B34C` | лунное золото |
| Акцент «Позитив» | `#7FA8A0` | приглушённый тил |
| Подсветка «сегодня» / выбор | `#E0B34C` | кольцо текущего дня |
| Деструктив | `#C96F5A` | удаление, ошибки |

## Уровни шкал настроения (1→5)

Градиенты от приглушённого к насыщенному для индикаторов (календарь, шкалы-круги).

## Светлая тема

Не выбрана. Зафиксировать после выбора из вариантов (см. раздел 13). До этого в макетах используется тёмная.

## Принципы

- Никакого неона, фиолетово-синих градиентов и «стеклянного» глянца.
- Приглушённые, «живые» цвета, один явный акцент на шкалу.
- Цвет не единственный носитель смысла: дублируется положением и формой (NFR-14).
