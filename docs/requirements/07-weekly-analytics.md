# 07. Еженедельный анализ и советы

Раз в неделю приложение анализирует записи и показывает отчёт: поддерживает за достижения и предлагает шаги по улучшению жизни.

## Общие правила

- Анализ выполняется локально на устройстве. Внешние сервисы и облачный ИИ не используются в первой версии (FR-06.4).
- Анализ основан на правилах и статистике. Машинное обучение не требуется.
- Советы формулируются шаблонами, но подставляют реальные данные пользователя (дни, значения, названия достижений).
- Правила, пороги и шаблоны фраз перечислены в разделе 15. Пороги и тексты хранятся в ресурсном файле (NFR-06).

## Требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-06.1 | Отчёт за прошлую неделю строится при первом запуске приложения начиная с понедельника 04:00. Фоновый планировщик не используется. | Must |
| FR-06.2 | Отчёт использует записи за прошлую неделю (пн–вс). День представляется вечерней записью, при её отсутствии — средним дневных чек-инов. Если данных меньше трёх дней, отчёт говорит об этом и не делает выводов. | Must |
| FR-06.3 | Отчёт содержит четыре части: итоги недели, достижения, закономерности, советы. | Must |
| FR-06.4 | Анализ выполняется на устройстве без интернета. Облачный ИИ не используется в первой версии. Вариант с локальной языковой моделью отложен (Q-08). | Must |
| FR-06.5 | Закономерности ищутся по правилам раздела 15: например, «дни с энергией 4 и выше чаще совпадают с блоком „сдал задачу“», «низкий позитив повторяется после дней с блоком „тревожно“». Закономерность выводится, только если выполнены пороги правила (минимум наблюдений и разница). Для закономерностей берутся данные за последние 4 недели, для итогов — за прошлую неделю. | Must |
| FR-06.6 | Готовый отчёт открывается автоматически один раз. Если при запуске открылся мастер, отчёт показывается после итогового экрана (FR-01.5). | Must |
| FR-06.7 | Отчёт сохраняется в истории. Историю отчётов можно открыть со страницы «Аналитика» (FR-05.10). | Must |
| FR-06.8 | Блок «Достижения» в отчёте называет конкретные достижения недели и поддерживает пользователя. Тон тёплый, без оценочных ярлыков. | Must |
| FR-06.9 | Советы разбиты по направлениям жизни (см. таблицу ниже). В отчёте не больше трёх советов за неделю, чтобы он не превращался в список задач. | Should |
| FR-06.10 | Совет включает конкретный шаг на следующую неделю, а не общую фразу. | Should |
| FR-06.11 | Если в записях нет данных для направления, совет по нему не выводится. | Must |
| FR-06.12 | Пользователь может отметить совет как «полезно» или «не актуально». Эта оценка учитывается при подборе следующих советов. | Could |
| FR-06.13 | Генерация отчёта идёт в фоновом потоке и не блокирует интерфейс. Если запись за прошлую неделю изменили задним числом, готовый отчёт не пересчитывается: после изменения день в календаре может отличаться от значения в старом отчёте, это ожидаемо. | Should |
| FR-06.14 | Если за прошлую неделю отчёт не построился (не было запусков, мало данных), пропущенные недели не догоняются: строится только отчёт за последнюю завершённую неделю. | Should |

## Направления жизни

Каждый блок привязан к направлению (FR-04.12). Направление «Без направления» в советах не участвует.

| Направление | Примеры сигналов в записях |
|---|---|
| Сон | Блоки «сонно», энергия 1–2 в начале недели |
| Работа и учёба | Блоки «работа», «учёба», «сдал задачу» |
| Здоровье и спорт | Блоки «спорт», «прогулка» |
| Отношения | Блоки «помог кому-то», «одиноко» |
| Быт | Блоки «уборка», «готовка», «покупки» |
| Эмоции | Частые «тревожно», «раздражён», низкий позитив |

## Пример отчёта

«Неделя прошла ровно. Энергия выше 3 в четыре дня из семи. Вы закончили два проекта (вторник, пятница). Заметно, что после дней с отметкой „спорт“ позитив на следующий день выше. Шаг на неделю: одна прогулка в день вне работы».

Пример показывает стиль, а не точный текст. Шаблоны фраз пишутся отдельно.
